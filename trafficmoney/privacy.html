TrafficMoney 개인정보처리방침

시행일: 2026년 11월 5일 · 운영: LIA 컴퍼니 (정규철) · 문의: jkc45621@gmail.com

TrafficMoney(이하 "앱")는 사용자가 본인의 광고·제휴 수익(AdMob, AdSense, 네이버 블로그 리워드, 카카오 애드핏, 쿠팡파트너스 등)을 한 화면과 홈 화면 위젯에서 확인하도록 돕는 앱입니다. 앱은 별도의 서버를 운영하지 않으며, 사용자의 데이터를 운영자에게 전송하거나 수집하지 않습니다.

1. 처리하는 정보와 처리 위치

정보어디서 오는가어디에 저장되는가
AdMob·AdSense 수익과 지표(예상 수익, 노출수, 클릭수, 페이지뷰 등), 게시자 ID, 계정 시간대·통화, AdSense 지급 정보사용자가 허용한 Google 계정에서 Google 공식 API(읽기 전용 권한 admob.readonly, adsense.readonly)로 조회사용자 기기 안(앱 전용 저장소)에만 저장
네이버 블로그 리워드 예상 수익·광고 노출·클릭, 카카오 애드핏 수익사용자가 앱 안에서 직접 로그인한 본인 계정의 보고서 화면을 기기 안에서 열어 읽음사용자 기기 안에만 저장
각 서비스의 로그인 상태(쿠키), Google 접근 토큰사용자의 로그인기기의 시스템 웹뷰·Google Play 서비스가 관리하며 앱 운영자에게 전송되지 않음

앱은 위 정보를 수익 표시, 기간별 합계·비교, 위젯 표시 목적으로만 사용합니다. 비밀번호는 각 서비스의 로그인 화면에 사용자가 직접 입력하며 앱이 저장하지 않습니다.

2. 제3자 제공 및 외부 전송

앱은 사용자 정보를 운영자나 제3자에게 제공·판매·공유하지 않습니다. 앱이 하는 네트워크 통신은 사용자가 연동한 서비스(Google, 네이버, 카카오, 쿠팡)에 사용자 본인의 데이터를 요청하는 것뿐이며, 모든 통신은 HTTPS로 암호화됩니다.

3. Google 사용자 데이터

앱이 Google API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 준수합니다. 앱은 읽기 전용 권한만 요청하며, Google 계정의 어떤 설정이나 데이터도 변경하지 않습니다. Google 데이터는 광고 목적으로 사용하거나 사람이 열람하지 않습니다.

4. 보관 기간과 삭제

  • 정보는 사용자가 연동을 해제하거나 앱을 삭제할 때까지 기기에만 보관됩니다.
  • 앱의 연동 화면에서 "연결됨"을 누르면 해당 소스의 저장 데이터와 로그인 정보가 지워집니다.
  • 앱을 삭제하면 기기에 저장된 모든 데이터가 함께 삭제됩니다.
  • Google 접근 권한은 Google 계정 → 서드 파티 연결에서 언제든 철회할 수 있습니다.

5. 진단 정보

보고서 화면을 읽지 못했을 때 앱은 원인 파악을 위한 진단 파일을 기기 안에 만듭니다. 이 파일은 사용자가 "진단 보내기"를 눌러 직접 공유할 곳을 고를 때만 기기 밖으로 나갑니다.

6. 광고

현재 버전에는 광고가 없습니다. 향후 AdMob 광고를 넣는 경우, Google이 광고 제공을 위해 기기 식별자 등을 처리할 수 있으며 이 방침을 갱신해 알립니다.

7. 아동

앱은 만 18세 이상 사용자를 대상으로 하며, 아동의 개인정보를 의도적으로 처리하지 않습니다.
